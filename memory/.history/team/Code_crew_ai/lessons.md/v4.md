- Contractions (it's, don't): a regex like \b\w+\b splits them in two; decide how they're counted explicitly (sess_52c2b6375503: builder#2 commit refused because tests failed)
- Tests go where existing tests live (see repo-facts); one session wrongly created a new tests/ folder
- Exception to the line above: Rust integration tests MUST live in tests/<name>.rs (or a Cargo.toml [[test]] entry). A root-level .rs file is not compiled by `cargo test`, so "repo root" from repo-facts only applies to the Python tests here
- test-writer: commit your own tests before finish(pass); re-running the builder's tests was rejected (sess_52c2b6375503: harness rejected finish)
- Always call finish appropriately; multiple harness nudges occurred due to agents stopping without calling finish (sess_52c2b6375503: harness nudge(s))
- test-writer: read memory first; call memory_list, then memory_read or memory_grep the notes relevant to this task before changing files (sess_418118aaa560: test-writer#1 write_file error)
- reviewer: always call finish() after reviewing; the harness nudged a session for skipping this (sess_c805c037788c: harness nudge)
- Avoid prefixing variables with underscores unless they are intentionally unused; implement the full functionality instead of leaving placeholders
