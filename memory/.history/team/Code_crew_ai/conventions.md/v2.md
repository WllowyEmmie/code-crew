---
name: conventions
description: Coding style this repo follows (naming, docstrings, structure)
---
- Functions are lowercase snake_case
- Every function has a one-line docstring saying what it returns
- Strings are built with f-strings
- Rust code lives in a single crate at the repo root (Cargo.toml + src/lib.rs); unit tests go in a `#[cfg(test)] mod tests` inside the same file, since repo-facts says tests live at the repo root
- Run `cargo fmt` (not hand edits) before committing: git_commit enforces cargo fmt --check and clippy -D warnings
